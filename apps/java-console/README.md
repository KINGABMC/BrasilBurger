# Brasil Burger - Java Console Application

Application console Java pour la gestion des produits Brasil Burger (examen).

## Fonctionnalités
- Gestion des produits (burgers, menus, compléments)
- Upload d'images vers Cloudinary
- Composition de menus
- Archivage/restauration de produits

## Stack Technique
- Java 17
- Maven
- PostgreSQL (NeonDB)
- Cloudinary (stockage images)
- Render (déploiement)
